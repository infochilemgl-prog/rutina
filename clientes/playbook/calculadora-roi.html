Cómo se calcula
  1. Visitas al mes = seguidores × % que visita.
  2. Pedidos web = visitas × % que compra.
  3. Ticket web = ticket actual × (1 + packs) × (1 + precio web).
  4. Ganancia por pedido = ticket web − costo de las prendas (el costo sube con los packs, el precio web es margen puro).
  5. Semanas = inversión ÷ ganancia semanal. Envío lo paga el cliente final.
